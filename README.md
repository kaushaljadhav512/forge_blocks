# forge_blocks

Force-only FORGE baseline for inserting a block into a 3D-printed slot on the Franka. This is
the baseline for the project *FORGE on the Franka, with Moment Feedback*.

It is an add-on package for **Isaac Lab v2.3.2**. It subclasses FORGE (`isaaclab_tasks/direct/forge`)
and does not modify Isaac Lab, so upstream code stays pinned and untouched.

## Layout

| Path | Runs on | What it does |
|---|---|---|
| `forge_blocks/geometry.py` | anywhere | Block and slot dimensions (**placeholders: measure the real parts**) |
| `forge_blocks/tasks/` | training PC | Task configs, the gym IDs below, and `ForgeBlocksEnv` (adds an error-radius option) |
| `forge_blocks/assets/*.usda` | — | Generated by `scripts/make_assets.py` from `geometry.py` |
| `scripts/train.py`, `play.py` | training PC | Run Isaac Lab's own rl_games scripts with our tasks registered |
| `scripts/eval_sweep.py` | training PC | Success, time to insert, peak force and success prediction for each error distance |
| `scripts/export_policy.py` | either | Checkpoint → `policy.pt` (TorchScript, includes the obs normaliser) + `runner_config.json` |
| `scripts/sim_bridge_test.py` | training PC | Drives the sim through the deploy runner; checks obs, actions and targets match ForgeEnv |
| `deploy/policy_runner.py` | laptop / robot PC | numpy + torch only. Builds observations and turns policy output into pose targets |
| `tests/` | anywhere | `python -m unittest discover tests` |

### Task IDs

| ID | What |
|---|---|
| `Isaac-Forge-PegInsert-Direct-v0` | Upstream FORGE peg (Phase 1 training) |
| `Isaac-ForgeBlocks-Peg8mm-Direct-v0` | Same peg, plus the error-radius option (use for `eval_sweep`; checkpoints are interchangeable) |
| `Isaac-ForgeBlocks-Block{5,2,1}mm-Direct-v0` | Block into a slot with 5, 2 or 1 mm total clearance |

## Training PC setup (RTX 4080)

```bash
# 1. Isaac Sim 5.1 + Isaac Lab v2.3.2 (see Isaac Lab install docs), then:
cd ~/IsaacLab && git checkout v2.3.2 && ./isaaclab.sh --install rl_games
# 2. This repo
git clone git@github.com:<you>/forge_blocks.git ~/forge_blocks
cd ~/IsaacLab && ./isaaclab.sh -p -m pip install -e ~/forge_blocks
```

`isaaclab.sh` exports `ISAACLAB_PATH`, which the wrappers use to find Isaac Lab's scripts.
Always launch through `./isaaclab.sh -p`. Run long jobs inside `tmux`.

## Workflow

```bash
cd ~/IsaacLab
# Phase 0: time a short run
./isaaclab.sh -p ~/forge_blocks/scripts/train.py --task Isaac-Forge-PegInsert-Direct-v0 --headless --max_iterations 20

# Phase 1: reproduce the peg (3 seeds)
./isaaclab.sh -p ~/forge_blocks/scripts/train.py --task Isaac-Forge-PegInsert-Direct-v0 --headless --seed 0 \
    agent.params.config.name=peg_seed0

# Phase 2: blocks. Train with error up to 5 mm in a random direction:
./isaaclab.sh -p ~/forge_blocks/scripts/train.py --task Isaac-ForgeBlocks-Block2mm-Direct-v0 --headless --seed 0 \
    env.obs_rand.use_xy_radius=true "env.obs_rand.fixed_asset_pos_xy_radius=[0.0,0.005]" \
    agent.params.config.name=block2mm_err5_seed0

# Evaluate at fixed error distances
./isaaclab.sh -p ~/forge_blocks/scripts/eval_sweep.py --task Isaac-ForgeBlocks-Block2mm-Direct-v0 --headless \
    --checkpoint logs/rl_games/block2mm_err5_seed0/<timestamp>/nn/block2mm_err5_seed0.pth \
    --errors_mm 0 5 10 20 30 --out results/block2mm_err5_seed0.csv

# Export, then check the deploy path against the sim before going near the robot
./isaaclab.sh -p ~/forge_blocks/scripts/export_policy.py logs/rl_games/.../nn/block2mm_err5_seed0.pth \
    --out exports/block2mm_err5_seed0
./isaaclab.sh -p ~/forge_blocks/scripts/sim_bridge_test.py --task Isaac-ForgeBlocks-Block2mm-Direct-v0 \
    --export exports/block2mm_err5_seed0 --headless
```

Copy `exports/<name>/` to the laptop or robot PC with `scp`, or attach it to a GitHub Release.

## Things to know before trusting results

- **Geometry is placeholder.** Measure the block and the printed slots, edit `geometry.py`, and
  rerun `make_assets.py`. `geometry.check()` rejects blocks too wide for the gripper, and blocks too
  short for the fingers to clear the rim.
- **Error distribution.** FORGE's own `obs_rand.fixed_asset_pos` is a per-axis Gaussian *sigma*,
  not a distance. Our grid uses `use_xy_radius` (uniform radius, random direction) instead.
- **Yaw.** Slot yaw is not randomised and the hand starts at yaw 0, because a square block
  needs alignment the policy cannot observe. On the robot, align the block's yaw with the slot
  before each attempt. FORGE's yaw action covers about −90° to +180° of hand yaw.
- **5 mm clearance and success.** Factory counts success only when the block is centred within
  2.5 mm, and 5 mm of clearance allows exactly that much play, so a few fully inserted blocks
  may count as failures.
- **Force sign on the robot.** In sim, the force is the joint reaction at the `force_sensor` link,
  in world axes. libfranka's `O_F_ext_hat_K` may have the opposite sign. Check with a press test
  and set `force_sign` in `RunnerConfig`.
- **Start pose.** Sim starts the hand within ±2 cm of the *true* slot. On the robot, start above
  the *estimated* slot.
